Fabric Tenant Settings Governance

Client test runbook and complete read-only source code

Purpose: identify capacity-level tenant-setting overrides, compare them with tenant defaults, map override records to capacity names, and produce HTML and CSV reports.

What the report proves

  • An override row proves that a capacity has an explicit setting instead of simply inheriting the tenant setting.
  • The report separately identifies effective drift in enabled state, security-group scope, or setting properties.
  • A same-state explicit override is still important: it can become drift later if the tenant default changes.
  • The inventory API does not return the actor or change timestamp. Use Microsoft Purview audit events for that evidence.

APIs used

PurposeMethod and endpointMutation
Tenant settingsGET https://api.fabric.microsoft.com/v1/admin/tenantsettingsNone
Capacity overridesGET https://api.fabric.microsoft.com/v1/admin/capacities/delegatedTenantSettingOverridesNone
Capacity names and metadataGET https://api.powerbi.com/v1.0/myorg/admin/capacitiesNone
Deliberately not called: POST https://api.fabric.microsoft.com/v1/admin/tenantsettings/{tenantSettingName}/update and the capacity override update endpoint. Both change configuration and are outside this audit workflow.

Permissions and prerequisites

  • Run as a Fabric administrator (Fabric Service Administrator).
  • Delegated API scope: Tenant.Read.All or Tenant.ReadWrite.All. Read-only permission is sufficient for the inventory calls.
  • Windows PowerShell 5.1 or PowerShell 7.
  • Azure CLI.
  • Python 3 available as python.

Authentication model

The application uses delegated user authentication through Azure CLI. The client enters only the Microsoft Entra tenant GUID. The application never asks for a password, client secret, or access token. Azure CLI obtains separate tokens for the two required audiences:

APIToken audience/resourceRequired role
Fabric Admin REST APIhttps://api.fabric.microsoft.comFabric administrator
Power BI Admin REST APIhttps://analysis.windows.net/powerbi/apiFabric/Power BI administrator
Activating an administrator role through Microsoft Entra Privileged Identity Management may be required before signing in. If the role was just activated, sign out and sign in again so that new tokens contain the current authorization.

Run the localhost report end to end

  1. Extract the package to a local folder.
  2. Open PowerShell in that folder.
  3. Start the local application: 
    python .\fabric_tenant_settings_server.py
  4. Open http://127.0.0.1:8000.
  5. Enter the Microsoft Entra tenant GUID at the top of the dashboard.
  6. Select Sign in & load. Azure CLI opens Microsoft sign-in and requests Fabric and Power BI tokens for that tenant. If already authenticated, select Load using current sign-in.
  7. Optional command-line authentication: 
    az login --tenant <CLIENT-TENANT-ID> --allow-no-subscriptions
  8. Optional account confirmation: 
    az account show --query "{user:user.name, tenantId:tenantId}" --output table
  9. Use Export CSV or Export JSON in the dashboard. Stop the server with Ctrl+C.

Test the Microsoft APIs directly

Use these tests when the localhost application cannot retrieve data. They isolate authentication, authorization, and API availability before the report code is involved.

1. Confirm Azure CLI is installed

az version

If the command is not found, install Azure CLI and open a new PowerShell window.

2. Sign into the exact tenant

$tenantId = "<CLIENT-TENANT-GUID>"
az login --tenant $tenantId --allow-no-subscriptions

3. Confirm the identity and tenant

az account show --query "{account:user.name, tenantId:tenantId}" --output table

The returned tenantId must exactly match the client tenant GUID.

4. Confirm a Fabric token can be issued

az account get-access-token `
  --tenant $tenantId `
  --resource https://api.fabric.microsoft.com `
  --query "{tenant:tenant, expiresOn:expiresOn}" `
  --output table

5. Retrieve tenant settings

az rest `
  --method get `
  --resource https://api.fabric.microsoft.com `
  --url "https://api.fabric.microsoft.com/v1/admin/tenantsettings" `
  --output json

Expected: HTTP 200 with a JSON value array containing tenant settings.

6. Retrieve capacity override records

az rest `
  --method get `
  --resource https://api.fabric.microsoft.com `
  --url "https://api.fabric.microsoft.com/v1/admin/capacities/delegatedTenantSettingOverrides" `
  --output json

Expected: HTTP 200. An empty value array is valid and means no current capacity-level overrides were returned.

7. Retrieve the tenant capacity inventory

az rest `
  --method get `
  --resource https://analysis.windows.net/powerbi/api `
  --url "https://api.powerbi.com/v1.0/myorg/admin/capacities" `
  --output json

This call supplies capacity names, regions, SKUs, and states for the override report.

Troubleshooting

SymptomLikely causeResolution
az is not recognizedAzure CLI is not installed or the terminal predates installation.Install Azure CLI and open a new PowerShell window.
Browser says connection refusedThe local Python server is not running.Run python .\fabric_tenant_settings_server.py and keep that terminal open.
Port 8000 is already in useAnother application is using the default port.Run python .\fabric_tenant_settings_server.py --port 8001 and open http://127.0.0.1:8001.
Tenant ID validation errorA tenant domain or subscription ID was entered instead of the tenant GUID.Use the Microsoft Entra tenant ID in GUID format.
Forbidden or HTTP 403The user is not a Fabric administrator, PIM is inactive, or the token predates role activation.Activate the Fabric administrator role, then run az logout and sign in again.
AADSTS authentication errorConditional Access, MFA, tenant restriction, or consent policy blocked authentication.Copy the full AADSTS code and request review from the client's identity administrator.
Tenant settings work but capacities failThe Power BI token audience or administrator permission is unavailable.Run the direct Power BI capacity test above using the exact Power BI resource URI.
Overrides array is emptyNo capacity settings are explicitly overridden.This is a valid compliant result, not an API failure.
Override exists but shows “matches tenant”The capacity has an explicit value equal to the current tenant value.Retain it as governance evidence; it can become drift when the tenant value changes.

Minimum support evidence

If the client still cannot call the APIs, collect the following without sharing access tokens:

  • Azure CLI version.
  • Tenant GUID and signed-in account name.
  • Whether the Fabric administrator role is permanent or PIM-activated.
  • The failing endpoint and HTTP status.
  • The Fabric requestId, error code, and message.
  • The complete AADSTS code if authentication failed.

How to interpret the result

Report resultMeaning
Override records = 0No capacity-level tenant-setting overrides were returned for the tenant.
Override exists, enabled state is SameThe capacity has an explicit override, but its enabled state currently matches the tenant.
Enabled drift = DifferentThe capacity is enabled while the tenant is disabled, or vice versa.
Security scope = DifferentEnabled/excluded Microsoft Entra groups differ from the tenant setting.
Properties = DifferentOne or more typed setting properties differ.
Workspace delegation is EnabledThe capacity setting can be delegated further to workspace administrators.

Actor and timestamp audit

Configuration inventory and audit history answer different questions. The REST report answers “what is overridden now?” For “who changed it and when?”, search Microsoft Purview audit for:

  • UpdatedAdminFeatureSwitch
  • UpdateCapacityTenantSettingDelegation
  • UpdateDomainTenantSettingDelegation
  • UpdateWorkspaceTenantSettingDelegation

fabric_tenant_settings_server.py
#!/usr/bin/env python3
"""Local read-only Fabric tenant-settings governance API and dashboard."""

from __future__ import annotations

import argparse
import base64
import csv
import io
import json
import shutil
import subprocess
import threading
import urllib.error
import urllib.parse
import urllib.request
import uuid
import webbrowser
from datetime import datetime, timezone
from http import HTTPStatus
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from typing import Any

from generate_fabric_tenant_settings_report import as_list, build_rows

FABRIC_RESOURCE = "https://api.fabric.microsoft.com"
POWER_BI_RESOURCE = "https://analysis.windows.net/powerbi/api"
POWER_BI_CAPACITIES_URL = "https://api.powerbi.com/v1.0/myorg/admin/capacities"
SKILL_HEADER = "fabriciq-ontology-cli"


class GovernanceStore:
    def __init__(self, output_directory: Path) -> None:
        self.output_directory = output_directory
        self.lock = threading.Lock()
        self.data: dict[str, Any] = {
            "status": "not_loaded",
            "lastRefreshedUtc": None,
            "error": None,
            "tenantId": None,
            "accountName": None,
            "tenantSettings": [],
            "capacityOverrideGroups": [],
            "capacities": [],
            "overrides": [],
        }

    @staticmethod
    def access_token(resource: str, tenant_id: str) -> tuple[str, dict[str, Any]]:
        azure_cli = shutil.which("az") or shutil.which("az.cmd")
        if not azure_cli:
            raise RuntimeError(
                "Azure CLI was not found. Install it and restart the terminal."
            )
        result = subprocess.run(
            [
                azure_cli,
                "account",
                "get-access-token",
                "--resource",
                resource,
                "--tenant",
                tenant_id,
                "--query",
                "accessToken",
                "--output",
                "tsv",
            ],
            check=False,
            capture_output=True,
            text=True,
        )
        if result.returncode:
            message = result.stderr.strip() or result.stdout.strip()
            raise RuntimeError(f"Azure CLI authentication failed: {message}")
        token = result.stdout.strip()
        if not token:
            raise RuntimeError("Azure CLI returned an empty access token.")
        try:
            payload = token.split(".")[1]
            payload += "=" * (-len(payload) % 4)
            claims = json.loads(base64.urlsafe_b64decode(payload))
        except (IndexError, ValueError, json.JSONDecodeError) as error:
            raise RuntimeError("Azure CLI returned an invalid access token.") from error
        if claims.get("tid", "").lower() != tenant_id.lower():
            raise RuntimeError(
                f"Token tenant {claims.get('tid')} does not match requested tenant {tenant_id}."
            )
        return token, claims

    @staticmethod
    def validate_tenant_id(tenant_id: str) -> str:
        try:
            return str(uuid.UUID(tenant_id.strip()))
        except ValueError as error:
            raise RuntimeError("Tenant ID must be a valid Microsoft Entra tenant GUID.") from error

    @staticmethod
    def interactive_login(tenant_id: str) -> None:
        azure_cli = shutil.which("az") or shutil.which("az.cmd")
        if not azure_cli:
            raise RuntimeError(
                "Azure CLI was not found. Install it and restart the terminal."
            )
        result = subprocess.run(
            [
                azure_cli,
                "login",
                "--tenant",
                tenant_id,
                "--allow-no-subscriptions",
                "--output",
                "none",
            ],
            check=False,
            capture_output=True,
            text=True,
            timeout=300,
        )
        if result.returncode:
            message = result.stderr.strip() or result.stdout.strip()
            raise RuntimeError(f"Azure CLI sign-in failed: {message}")

    @staticmethod
    def request_json(url: str, token: str, fabric_request: bool = False) -> dict[str, Any]:
        headers = {"Authorization": f"Bearer {token}", "Accept": "application/json"}
        if fabric_request:
            headers["x-ms-fabric-skill"] = SKILL_HEADER
        request = urllib.request.Request(url, headers=headers, method="GET")
        try:
            with urllib.request.urlopen(request, timeout=60) as response:
                return json.load(response)
        except urllib.error.HTTPError as error:
            body = error.read().decode("utf-8", errors="replace")
            raise RuntimeError(f"GET {url} failed with HTTP {error.code}: {body}") from error
        except urllib.error.URLError as error:
            raise RuntimeError(f"GET {url} failed: {error.reason}") from error

    def paged_fabric_data(self, url: str, token: str) -> list[dict[str, Any]]:
        records: list[dict[str, Any]] = []
        while url:
            response = self.request_json(url, token, fabric_request=True)
            records.extend(as_list(response.get("value")))
            url = str(response.get("continuationUri") or "")
        return records

    def refresh(self, tenant_id: str | None = None) -> dict[str, Any]:
        with self.lock:
            self.data["status"] = "refreshing"
            self.data["error"] = None
            try:
                requested_tenant = self.validate_tenant_id(
                    tenant_id or str(self.data.get("tenantId") or "")
                )
                fabric_token, fabric_claims = self.access_token(
                    FABRIC_RESOURCE, requested_tenant
                )
                power_bi_token, _ = self.access_token(
                    POWER_BI_RESOURCE, requested_tenant
                )
                tenant_settings = self.paged_fabric_data(
                    f"{FABRIC_RESOURCE}/v1/admin/tenantsettings", fabric_token
                )
                override_groups = self.paged_fabric_data(
                    f"{FABRIC_RESOURCE}/v1/admin/capacities/delegatedTenantSettingOverrides",
                    fabric_token,
                )
                capacities_response = self.request_json(
                    POWER_BI_CAPACITIES_URL, power_bi_token
                )
                capacities = as_list(capacities_response.get("value"))
                overrides = build_rows(tenant_settings, override_groups, capacities)
                refreshed = datetime.now(timezone.utc).isoformat()

                self.output_directory.mkdir(parents=True, exist_ok=True)
                snapshots = {
                    "tenant-settings.json": tenant_settings,
                    "capacity-overrides.json": override_groups,
                    "admin-capacities.json": capacities_response,
                    "normalized-overrides.json": overrides,
                }
                for name, value in snapshots.items():
                    (self.output_directory / name).write_text(
                        json.dumps(value, indent=2), encoding="utf-8"
                    )

                self.data = {
                    "status": "ready",
                    "lastRefreshedUtc": refreshed,
                    "error": None,
                    "tenantId": requested_tenant,
                    "accountName": (
                        fabric_claims.get("preferred_username")
                        or fabric_claims.get("upn")
                        or fabric_claims.get("appid")
                        or "Unknown identity"
                    ),
                    "tenantSettings": tenant_settings,
                    "capacityOverrideGroups": override_groups,
                    "capacities": capacities,
                    "overrides": overrides,
                }
            except Exception as error:
                self.data["status"] = "error"
                self.data["error"] = str(error)
            return self.summary()

    def connect(self, tenant_id: str, interactive: bool) -> dict[str, Any]:
        requested_tenant = self.validate_tenant_id(tenant_id)
        if interactive:
            self.interactive_login(requested_tenant)
        return self.refresh(requested_tenant)

    def summary(self) -> dict[str, Any]:
        rows = self.data["overrides"]
        return {
            "status": self.data["status"],
            "lastRefreshedUtc": self.data["lastRefreshedUtc"],
            "error": self.data["error"],
            "tenantId": self.data["tenantId"],
            "accountName": self.data["accountName"],
            "tenantSettings": len(self.data["tenantSettings"]),
            "capacities": len(self.data["capacities"]),
            "capacitiesWithOverrides": len({row["capacity_id"] for row in rows}),
            "overrideRecords": len(rows),
            "enabledStateDrift": sum(row["enabled_state_differs"] for row in rows),
            "securityScopeDrift": sum(row["security_scope_differs"] for row in rows),
            "propertyDrift": sum(row["properties_differ"] for row in rows),
        }

class GovernanceHandler(BaseHTTPRequestHandler):
    store: GovernanceStore

    def log_message(self, format_string: str, *args: Any) -> None:
        print(f"{self.address_string()} - {format_string % args}")

    def send_bytes(self, body: bytes, content_type: str, status: HTTPStatus = HTTPStatus.OK) -> None:
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store")
        self.send_header("X-Content-Type-Options", "nosniff")
        self.end_headers()
        self.wfile.write(body)

    def send_json(self, value: Any, status: HTTPStatus = HTTPStatus.OK) -> None:
        self.send_bytes(
            json.dumps(value, indent=2).encode("utf-8"),
            "application/json; charset=utf-8",
            status,
        )

    def do_GET(self) -> None:
        path = urllib.parse.urlparse(self.path).path
        if path == "/":
            self.send_bytes(DASHBOARD_HTML.encode("utf-8"), "text/html; charset=utf-8")
        elif path == "/health":
            self.send_json({"status": "ok", "dataStatus": self.store.data["status"]})
        elif path == "/api/summary":
            self.send_json(self.store.summary())
        elif path == "/api/capacities":
            self.send_json(self.store.data["capacities"])
        elif path == "/api/overrides":
            self.send_json(self.store.data["overrides"])
        elif path == "/api/settings":
            self.send_json(self.store.data["tenantSettings"])
        elif path == "/api/export.json":
            self.send_json(
                {"summary": self.store.summary(), "overrides": self.store.data["overrides"]}
            )
        elif path == "/api/export.csv":
            rows = self.store.data["overrides"]
            output = io.StringIO()
            if rows:
                writer = csv.DictWriter(output, fieldnames=list(rows[0]))
                writer.writeheader()
                writer.writerows(rows)
            self.send_bytes(
                output.getvalue().encode("utf-8-sig"),
                "text/csv; charset=utf-8",
            )
        else:
            self.send_json({"error": "Not found"}, HTTPStatus.NOT_FOUND)

    def do_POST(self) -> None:
        path = urllib.parse.urlparse(self.path).path
        try:
            if path == "/api/connect":
                length = int(self.headers.get("Content-Length", "0"))
                if length > 4096:
                    self.send_json(
                        {"error": "Request body is too large."},
                        HTTPStatus.REQUEST_ENTITY_TOO_LARGE,
                    )
                    return
                body = json.loads(self.rfile.read(length) or b"{}")
                summary = self.store.connect(
                    str(body.get("tenantId") or ""),
                    bool(body.get("interactive")),
                )
                status = (
                    HTTPStatus.OK
                    if summary["status"] == "ready"
                    else HTTPStatus.BAD_GATEWAY
                )
                self.send_json(summary, status)
            elif path == "/api/refresh":
                summary = self.store.refresh()
                status = (
                    HTTPStatus.OK
                    if summary["status"] == "ready"
                    else HTTPStatus.BAD_GATEWAY
                )
                self.send_json(summary, status)
            else:
                self.send_json({"error": "Not found"}, HTTPStatus.NOT_FOUND)
        except (RuntimeError, subprocess.TimeoutExpired, json.JSONDecodeError) as error:
            self.send_json({"error": str(error)}, HTTPStatus.BAD_REQUEST)


def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("--host", default="127.0.0.1")
    parser.add_argument("--port", type=int, default=8000)
    parser.add_argument("--output-directory", type=Path, default=Path(__file__).parent / "output")
    parser.add_argument("--tenant-id")
    parser.add_argument("--no-browser", action="store_true")
    args = parser.parse_args()

    if args.host not in {"127.0.0.1", "localhost"}:
        raise SystemExit("For safety, this application only binds to localhost.")

    store = GovernanceStore(args.output_directory)
    GovernanceHandler.store = store
    if args.tenant_id:
        store.refresh(args.tenant_id)
    server = ThreadingHTTPServer((args.host, args.port), GovernanceHandler)
    url = f"http://{args.host}:{args.port}"
    print(f"Fabric governance report running at {url}")
    if not args.no_browser:
        threading.Timer(0.6, lambda: webbrowser.open(url)).start()
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print("\nStopping local server.")
    finally:
        server.server_close()

def load_json(path: Path) -> Any:
    with path.open(encoding="utf-8-sig") as handle:
        return json.load(handle)


def as_list(value: Any) -> list[Any]:
    if value is None:
        return []
    return value if isinstance(value, list) else [value]


def canonical(value: Any) -> str:
    return json.dumps(value if value is not None else [], sort_keys=True, separators=(",", ":"))


def status_text(value: Any) -> str:
    if value is True:
        return "Enabled"
    if value is False:
        return "Disabled"
    return "Not specified"


def group_names(setting: dict[str, Any], key: str) -> str:
    groups = as_list(setting.get(key))
    return "; ".join(
        str(group.get("name") or group.get("graphId") or "")
        for group in groups
        if isinstance(group, dict)
    )


def property_text(setting: dict[str, Any]) -> str:
    return "; ".join(
        f"{item.get('name')}={item.get('value')}"
        for item in as_list(setting.get("properties"))
        if isinstance(item, dict)
    )


def build_rows(
    tenant_settings: list[dict[str, Any]],
    capacity_overrides: list[dict[str, Any]],
    capacities: list[dict[str, Any]],
) -> list[dict[str, Any]]:
    tenant_by_name = {item["settingName"]: item for item in tenant_settings}
    capacity_by_id = {item["id"]: item for item in capacities}
    rows: list[dict[str, Any]] = []

    for override_group in capacity_overrides:
        capacity_id = override_group["id"]
        capacity = capacity_by_id.get(capacity_id, {})
        for capacity_setting in as_list(override_group.get("tenantSettings")):
            setting_name = capacity_setting["settingName"]
            tenant_setting = tenant_by_name.get(setting_name, {})
            enabled_differs = tenant_setting.get("enabled") != capacity_setting.get("enabled")
            security_scope_differs = any(
                canonical(tenant_setting.get(key)) != canonical(capacity_setting.get(key))
                for key in ("enabledSecurityGroups", "excludedSecurityGroups")
            )
            properties_differ = canonical(tenant_setting.get("properties")) != canonical(
                capacity_setting.get("properties")
            )
            has_effective_drift = (
                enabled_differs or security_scope_differs or properties_differ
            )
            rows.append(
                {
                    "capacity_name": capacity.get("displayName", "Unknown capacity"),
                    "capacity_id": capacity_id,
                    "sku": capacity.get("sku", ""),
                    "state": capacity.get("state", ""),
                    "region": capacity.get("region", ""),
                    "setting_group": capacity_setting.get("tenantSettingGroup", ""),
                    "setting_title": capacity_setting.get("title", ""),
                    "setting_name": setting_name,
                    "tenant_enabled": status_text(tenant_setting.get("enabled")),
                    "capacity_enabled": status_text(capacity_setting.get("enabled")),
                    "classification": (
                        "Effective drift"
                        if has_effective_drift
                        else "Explicit override matches tenant"
                    ),
                    "enabled_state_differs": enabled_differs,
                    "tenant_enabled_groups": group_names(tenant_setting, "enabledSecurityGroups"),
                    "capacity_enabled_groups": group_names(
                        capacity_setting, "enabledSecurityGroups"
                    ),
                    "tenant_excluded_groups": group_names(tenant_setting, "excludedSecurityGroups"),
                    "capacity_excluded_groups": group_names(
                        capacity_setting, "excludedSecurityGroups"
                    ),
                    "security_scope_differs": security_scope_differs,
                    "tenant_properties": property_text(tenant_setting),
                    "capacity_properties": property_text(capacity_setting),
                    "properties_differ": properties_differ,
                    "delegate_to_workspace": status_text(
                        capacity_setting.get("delegateToWorkspace")
                    ),
                    "delegated_from": capacity_setting.get("delegatedFrom", ""),
                }
            )
    return sorted(rows, key=lambda row: (row["capacity_name"], row["setting_group"], row["setting_title"]))


def write_csv(path: Path, rows: list[dict[str, Any]]) -> None:

        writer = csv.DictWriter(handle, fieldnames=list(rows[0]) if rows else [])
        if rows:
            writer.writeheader()
            writer.writerows(rows)

def main() -> None:
    parser = argparse.ArgumentParser()
    parser.add_argument("snapshot_directory", type=Path)
    parser.add_argument("--focus-capacity-id")
    args = parser.parse_args()

    directory = args.snapshot_directory
    tenant_settings = as_list(load_json(directory / "tenant-settings.json"))
    capacity_overrides = as_list(load_json(directory / "capacity-overrides.json"))
    capacities_response = load_json(directory / "admin-capacities.json")
    capacities = as_list(
        capacities_response.get("value")
        if isinstance(capacities_response, dict)
        else capacities_response
    )

    rows = build_rows(tenant_settings, capacity_overrides, capacities)
    write_csv(directory / "fabric-capacity-tenant-setting-overrides.csv", rows)
    write_html(
        directory / "fabric-capacity-tenant-setting-overrides.html",
        rows,
        tenant_settings,
        capacities,
        args.focus_capacity_id,
    )
    print(
        json.dumps(
            {
                "tenantSettings": len(tenant_settings),
                "capacities": len(capacities),
                "capacitiesWithOverrides": len({row["capacity_id"] for row in rows}),
                "overrideRecords": len(rows),
                "enabledStateDrift": sum(row["enabled_state_differs"] for row in rows),
                "securityScopeDrift": sum(row["security_scope_differs"] for row in rows),
                "propertyDrift": sum(row["properties_differ"] for row in rows),
            },
            indent=2,
        )
    )


if __name__ == "__main__":
    main()
